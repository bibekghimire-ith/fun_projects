# Personal Portfolio + Blog — Claude Code Kit

This repository contains the engineering specification and Claude Code configuration for building a production-quality personal portfolio website with an integrated blog/CMS.

## Stack
- Python 3.12+
- Flask
- SQLAlchemy
- PostgreSQL
- Jinja2
- HTMX
- Bootstrap 5
- Vanilla JavaScript
- Gunicorn
- Docker
- pytest
- Ruff
- Black

## Important
This is a personal/professional portfolio application, not a financial portfolio manager.

## Usage
1. Copy this kit into a new Git repository.
2. Start Claude Code from the repository root.
3. Read CLAUDE.md and docs/MASTER_PROMPT.md.
4. Ask Claude Code to implement Phase 0.
5. Use `/build-phase` to continue.
6. Use `/test` after major changes.
7. Use `/security-audit` and `/review` before release.
8. Use `/deploy-check` before production deployment.
