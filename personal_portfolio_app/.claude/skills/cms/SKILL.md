# CMS Skill

Treat the blog as a real content-management system.

Implement:
- drafts
- preview
- publishing
- scheduling abstraction
- slugs
- categories
- tags
- featured posts
- SEO metadata
- Markdown
- sanitized rendering
- pagination
- search

Never render raw Markdown output as trusted HTML without sanitization.

Publishing should be explicit and auditable.

Avoid destructive deletion where an archive/soft-delete is more appropriate.
