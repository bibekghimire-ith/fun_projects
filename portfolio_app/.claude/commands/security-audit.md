# Security Audit

Perform a focused application security audit.

Check:
- authentication
- session security
- authorization
- IDOR
- CSRF
- XSS
- SQL injection
- SSRF
- unsafe redirects
- uploads
- secrets
- rate limiting
- security headers
- dependency vulnerabilities
- Docker security

Add regression tests for exploitable findings where appropriate.

Write docs/SECURITY_AUDIT.md with:
- severity
- evidence
- impact
- remediation
- status
