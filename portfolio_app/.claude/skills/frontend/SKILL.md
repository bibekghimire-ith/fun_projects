# Frontend Skill

Use Jinja2 + HTMX + Bootstrap 5 + modular vanilla JS.

Priorities:
1. accessibility
2. responsive behavior
3. visual consistency
4. progressive enhancement
5. minimal JavaScript

Use reusable components/macros.
Do not create a SPA.

Every asynchronous action should provide:
- loading
- success
- error
feedback.

Support:
- dark/light theme
- keyboard navigation
- focus states
- mobile navigation
- accessible forms
