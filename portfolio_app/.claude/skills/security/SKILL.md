# Security Skill

For every feature ask:

Authentication?
Authorization?
IDOR?
CSRF?
XSS?
SQL injection?
SSRF?
Unsafe redirect?
Mass assignment?
Upload abuse?
Secrets?
Logging leakage?
Rate limiting?
Security headers?
Dependency risk?

Every admin operation must require authorization.

Every browser mutation must have CSRF protection.

Never rely on UI restrictions as security controls.
