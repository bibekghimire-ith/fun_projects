# Implementation Prompt — Private Photos + Playlist

Implement the Photos + Playlist module.

## User stories

As a creator:
- I can create albums.
- I can upload photos/audio.
- I can reorder photos.
- I can add captions and dates.
- I can associate a song/audio track with a photo or memory.
- I can mark memories as hidden/unlocked.
- I can preview the gallery.
- I can choose one of five templates.

As recipient:
- I can browse a beautiful private gallery.
- I can open a photo full-screen.
- I can hear associated audio after interaction.
- I can explore by timeline.
- I can discover hidden memories when unlocked.

## Templates

1. Editorial
2. Film Strip
3. Polaroid
4. Midnight Gallery
5. Cinematic Scroll

## Rare differentiators

- "Photos we haven't taken yet" placeholders
- mood-based memory discovery
- photo-to-song association
- memory reveal
- voice caption
- future-memory cards

Implement domain/API/UI/tests, not just the gallery.
