# Implementation Prompt — Two Perspectives

Build collaborative two-person memories.

## Model

One memory has:
- shared metadata
- person A entry
- person B entry
- optional shared media

Entries can be:
- draft
- private
- visible
- approved

## Views

1. Split Screen
2. Mirror
3. Conversation
4. Polaroid Pair
5. Timeline Duel

## Differentiators

- "What I remember"
- "What you remember"
- side-by-side compare
- disagreement/difference highlights
- synchronized voice messages
- approval workflow

Both participants can contribute without exposing drafts to the other until configured.
