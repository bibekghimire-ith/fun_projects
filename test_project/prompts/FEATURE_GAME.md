# Implementation Prompt — Tiny Dating / Proposal Game

Build a reusable data-driven mini-game system.

## Templates

1. Cute Pixel Adventure — Phaser
2. Modern Interactive Story — React
3. Mini Puzzle — React
4. Visual Novel — React + motion
5. Arcade Choice — Phaser/React hybrid

## Engine concepts

Game:
- scenes
- characters
- choices
- conditions
- collectibles
- memories
- endings
- final question

Do not couple content to code.

## Example final flow

Collect memories -> solve/play -> reveal final scene -> ask:
"Will you go on a date with me?"

The creator can change the question.

Support:
- Yes/No
- custom options
- one-button CTA
- response capture

Include accessibility fallback for non-game interactions.
