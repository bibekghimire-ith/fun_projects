# AETHER — Configurable Personal AI Assistant

AETHER is a configurable Jarvis-style personal AI assistant platform. AETHER is only the
default project name; administrators can rename the assistant from settings.

## Vision
One assistant for conversation, memory, research, development, DevOps, automation and approved
computer/tool actions, while remaining useful offline.

## Core capabilities
- Chat and streaming
- Voice
- Multimodal interaction
- Local/offline AI
- Cloud AI adapters
- Memory
- RAG
- Browser automation
- Filesystem
- Shell/developer tools
- Git/GitHub
- Docker
- SSH
- PostgreSQL
- Google Calendar/Gmail
- Discord/Telegram
- Notion
- VS Code
- Automation
- Multi-user
- Admin controls
- Permissions/approvals
- Audit
- Extensible integrations/plugins

## MVP-3
This is intentionally a substantial MVP, not a toy prototype. The target includes the above
core architecture, local/offline mode, real tools, integrations, voice, automation, admin and
security controls.

## Start
```bash
cp .env.example .env
docker compose up --build
```
