# Product Requirements

## Goal
Provide a private, extensible personal AI operating layer capable of conversation and authorized
real-world software actions.

## Functional requirements
- streaming chat and conversation history
- voice input/output
- multimodal input
- local/cloud model providers
- short-term and long-term memory
- RAG with citations
- web/browser tools
- filesystem and developer tools
- Docker, SSH and PostgreSQL tools
- GitHub, Google Calendar, Gmail, Discord, Telegram, Notion, VS Code
- automation and scheduling
- multi-user accounts
- admin console
- configurable branding/name
- audit and security controls
- Dockerized deployment

## Acceptance
A fresh developer can clone, configure `.env`, run Docker Compose, use a local model, chat,
approve a tool action, inspect audit logs, ingest a document for RAG, create automation and
disable an integration from admin settings.
