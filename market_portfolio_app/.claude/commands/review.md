# Production Review

Review the current repository as a Principal Engineer.

Check:
- architecture
- data integrity
- financial calculations
- authorization/IDOR
- CSRF/XSS/SQL injection
- secrets
- migrations
- Docker portability
- logging/health checks
- test quality
- accessibility
- UI consistency
- dependency hygiene

Inspect actual files before making claims.

Create docs/REVIEW.md with:
- findings by severity
- evidence/file references
- recommended fixes
- whether each acceptance criterion is verified
Do not modify code unless explicitly requested.
