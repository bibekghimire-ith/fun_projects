# Frontend Skill

Use for templates, HTMX, Bootstrap, CSS, and Chart.js.

## Rules
- Responsive and accessible.
- Reusable base layout and components.
- No SPA unless necessary.
- Avoid excessive JavaScript.
- Every async interaction needs success/error/loading states.
- Tables must work on small screens.
- Charts must have accessible labels and useful empty states.
- Support dark/light theme.
- Never expose authorization decisions solely in UI; backend remains authoritative.
